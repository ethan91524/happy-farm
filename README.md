# 開心農場（單機復刻）

Facebook 版《開心農場》（Elex／6waves，2009，Flash）的單機復刻，純前端、無後端、不需登入。
這個 repo 只放**打包好的可玩檔案**，開發用的原始碼在本機。

| 頁面 | 說明 |
|---|---|
| [`index.html`](./) | 遊戲本體。單檔約 15 MB，所有圖片內嵌，第一次載入請等一下（行動網路會比較久） |
| [`expand-order.html`](./expand-order.html) | 開墾順序圖：35 塊地依解鎖順序編號 |
| [`crop-data.html`](./crop-data.html) | 作物數值核對：64 種作物逐項比對原站 `item.xml` |

進度會存在**這台裝置的瀏覽器**（localStorage），換手機或清除瀏覽資料就沒了。

## 目前完成度

- **農田**：7 欄 × 5 列共 35 塊。磚塊材質裁自原版截圖；開墾順序與拓地價目取自原站台灣版 `item.xml` 的 `<land>` 條目
- **作物**：64 種（原站商店全品項，欄位取自 2010-08-20 台灣版 `item.xml`）× 6 個生長階段，素材來自封存的原版資源
- **動物**：乳牛、綿羊、母雞（含雞巢）、鴨子、驢子、孔雀已換成原版圖；豬改用參考重建的立體模型（走動／轉身自繪，非原版資產）；蜜蜂、兔子、鴿子仍是低解析截圖切片，待補
- **數值**：64 種作物已逐項對照原站 `item.xml`；小麥那筆是原版資料自己矛盾（分期合計 43h vs `life_cycle` 41h）。核對頁比對的是 2009 版 `item.xml`，其中椰子樹、曼珠沙華、天山雪蓮、玉潔冰星、飛火流櫻 5 種只出現在 2010 版，因此顯示「找不到」，其數值仍逐項對過 2010 版
- **照顧**：長草／長蟲／太乾會影響收成——成熟前處理完不扣產量，漏掉的輪次把收成從 `output` 拉向 `min_output`，漏澆水另外讓成熟延後。動畫尚未製作
